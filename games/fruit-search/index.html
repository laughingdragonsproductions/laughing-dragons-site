Fruit Search

Hidden-object maps from the Laughing Dragons catalog - scan busy scenes and tap the Fruit Friend named in the prompt.

Fruit Search is an I-Spy style finder built around the Fruit Friends A-Z cast. Each round asks you to find a named character or a letter, then you scan the map and tap the right portrait. Wrong taps get a gentle try-again; correct finds celebrate and roll the next target.

How to play

  1. Read the prompt - find a character by name or by starting letter.
  2. Scan the map and tap the matching Fruit Friend portrait.
  3. Clear five finds to complete the round and earn your unlock code.

Difficulty

Choose Easy Orchard, Medium Grove, or Hard Harvest. Maps scale from a few large sprites to crowded scenes with smaller portraits. Switch between Name mode and Letter mode anytime.

Unlock requirement

Beat Memory Matching at or under par first - then Fruit Search opens from the Games hub. Clearing a round reveals code TRACE-A-Z-4 for Terminal Trainer.
