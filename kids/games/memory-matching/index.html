How to Play

  1. Tap a tile to flip it and reveal a dragon.
  2. Flip a second tile — if they match, both stay up and disappear.
  3. If they don't match, both flip back. Try to remember where each dragon was!
  4. Clear every pair to win. Fewer moves = better rating.
